# 🛡️ AWS Cloud Security Professional Bootcamp

Welcome to my Cloud Security portfolio. This repository contains a series of hands-on laboratories focused on securing cloud infrastructure within AWS, following the **Well-Architected Framework** and **Zero Trust** principles.

Throughout this bootcamp, I have evolved from basic identity management to advanced threat hunting and perimeter defense, demonstrating the ability to design, implement, and audit secure cloud environments.

## 🏗️ Architecture Overview
The labs cover a comprehensive multi-layered defense strategy:
1. **Identity (IAM):** Least privilege, permission boundaries, and auditing.
2. **Network (VPC):** Isolation, Bastion Hosts, and PrivateLink.
3. **Data (S3):** Encryption at rest/transit and Ransomware protection (WORM).
4. **Monitoring (SOC):** Threat hunting via CloudTrail and automated alerting.
5. **Application & Perimeter:** Secret management and DDoS resilience.

## 🛠️ Key Technical Competencies
* **Threat Hunting:** Ability to query and analyze CloudTrail logs to identify unauthorized Root access.
* **Infrastructure as Security:** Implementing "Tripwires" via EventBridge to alert on critical security events.
* **Data Integrity:** Ensuring data immutability via S3 Object Lock to prevent unauthorized deletion or encryption (Ransomware).
* **Network Hardening:** Designing private architectures that minimize the attack surface by avoiding public internet exposure.
